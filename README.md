# EC-MFU Form Helper

เครื่องมือช่วย **เตรียมเอกสารยื่นขอรับรองจริยธรรมการวิจัยในมนุษย์ (EC)** มหาวิทยาลัยแม่ฟ้าหลวง  
จัดทำโดย สำนักวิชาเทคโนโลยีดิจิทัลประยุกต์ (ADT) มหาวิทยาลัยแม่ฟ้าหลวง

อัปโหลดไฟล์ข้อเสนอโครงการ (`.docx` / `.pdf` ที่มีข้อความ / `.md` / `.txt`) แล้วเครื่องมือจะช่วยดึงข้อมูลมากรอกลงแบบฟอร์ม EC ให้ ตรวจและเติมช่องที่ยังว่าง จากนั้นสั่งพิมพ์แต่ละแบบฟอร์มเป็น PDF ได้

## ความเป็นส่วนตัว (สำคัญ)

- **เป็นเครื่องมือฝั่งเบราว์เซอร์ล้วน (client-side)** ไฟล์ข้อเสนอถูกอ่านและประมวลผลในเบราว์เซอร์ของผู้ใช้เท่านั้น
- **ไม่มีการส่งข้อมูลออกไปที่เซิร์ฟเวอร์ใด ๆ และไม่มีการบันทึกข้อมูล** (ไม่มี backend, ไม่มี API key, ไม่มีฐานข้อมูล)
- การบันทึกงาน/เปิดงานเป็นไฟล์ `.json` ที่อยู่บนเครื่องผู้ใช้เองทั้งหมด

## การใช้งาน

เปิดด้วยเว็บเซิร์ฟเวอร์สแตติกใด ๆ (เพราะใช้ ES modules) เช่น:

```bash
python3 -m http.server 8000
# แล้วเปิด http://127.0.0.1:8000/index.html
```

ขั้นตอน: 1) อัปโหลดข้อเสนอ 2) ตรวจและเติมข้อมูลที่ยังว่าง 3) เปิดแต่ละแบบฟอร์มแล้วสั่งพิมพ์เป็น PDF ตามคู่มือ Package การยื่นเสนอเอกสาร

## แบบฟอร์มที่รองรับ

AP 01_1, AP 01_2, AP 02, AP 03_1 และแบบแจ้งชำระค่าธรรมเนียม (ตามแบบฟอร์มทางการของสำนักงานคณะกรรมการจริยธรรมการวิจัยในมนุษย์ มฟล.)

## ข้อจำกัดความรับผิดชอบ

เอกสารที่ได้เป็น **ร่างให้ผู้วิจัยตรวจทานก่อนยื่น** ไม่ใช่การรับรองจริยธรรม และไม่ได้มาแทนการพิจารณาของคณะกรรมการจริยธรรมการวิจัยในมนุษย์ ผู้วิจัยมีหน้าที่ตรวจสอบความถูกต้องและครบถ้วนของข้อมูลทุกครั้งก่อนนำส่ง

## โครงสร้าง

- `index.html` — หน้าเครื่องมือหลัก
- `src/` — ตรรกะ: โหลดไฟล์, สกัดข้อมูล, เติมฟอร์ม, ส่วนช่วยร่าง
- `forms/` — แบบฟอร์ม EC (A4, TH Sarabun New) สำหรับพิมพ์เป็น PDF
- `assets/` — โลโก้/ทรัพยากรหน้าตา
