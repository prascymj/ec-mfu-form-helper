วิธีใช้งาน

เตรียมเอกสารยื่น EC มฟล. - สำนักวิชาเทคโนโลยีดิจิทัลประยุกต์
เปิดเครื่องมือ

ทำตาม 5 ขั้นตอนสั้นๆ นี้ ใช้เวลาไม่กี่นาที

  1. อัปโหลดไฟล์ข้อเสนอโครงการ

    ลากไฟล์ .docx (แนะนำ) หรือ .pdf ที่มีข้อความ / .html / .md / .txt มาวางในกรอบ หรือคลิกเพื่อเลือกไฟล์ ระบบจะอ่านและดึงข้อมูลให้อัตโนมัติ (ไฟล์อยู่ในเบราว์เซอร์ของคุณ ไม่ถูกส่งออกไปที่ใด)

    เลือกได้หลายไฟล์พร้อมกัน ระบบอ่านทีละไฟล์แล้วรวมเป็นชุดเดียว โดยไฟล์แรกที่เลือกมีผลก่อน ไฟล์ถัดไปเติมเฉพาะช่องที่ยังว่าง แบบฟอร์ม EC ที่กรอกแล้ว (Word, PDF หรือไฟล์ .doc ที่บันทึกจากหน้าแบบฟอร์ม) อัปโหลดร่วมได้ ค่าที่อ่านจากแบบฟอร์มมีผลก่อนค่าที่เดาจากข้อเสนอ

    รูปและตาราง: ข้อ 9, 10, 12.1.1, 12.3, 13 ของ AP 02 และข้อ 7 ของ AP 03_1 ใส่รูปและตารางได้ รูปและตารางในไฟล์ .docx ที่อยู่ใต้หัวข้อเหล่านี้จะถูกดึงมาให้เอง หรือกดปุ่ม แทรกรูป / แทรกตาราง ใต้ช่องข้อความ หรือวางรูปหรือตารางที่คัดลอกจาก Word หรือ Excel ลงในช่องได้โดยตรง ข้อความ [[รูป 1]] หรือ [[ตาราง 1]] คือตำแหน่งที่รูปหรือตารางจะปรากฏบนแบบฟอร์ม

  2. ตรวจและเติมข้อมูลที่ยังว่าง

    ระบบจะกรอกข้อมูลลงแบบฟอร์มให้ แล้วติดป้ายสีบอกสถานะแต่ละช่อง แก้ไขหรือพิมพ์เพิ่มได้ทุกช่อง เน้นเติมช่อง สีแดง ให้ครบ และตรวจช่อง สีเหลือง ว่าถูกต้อง

    กล่องด้านบนสุดของส่วนนี้แสดงรายการข้อที่ยังว่างและข้อที่ควรตรวจ คลิกชื่อข้อเพื่อไปที่ช่องนั้น หรือกดปุ่มด้านล่างจอ "ไปข้อที่ต้องกรอกถัดไป" ข้อสีเหลืองที่ถูกต้องแล้ว (เช่น ลอกจากข้อเสนอแต่อ่านง่ายอยู่แล้ว) กดปุ่ม ยืนยัน ที่ข้อนั้นได้โดยไม่ต้องแก้ข้อความ

    กรอกและแก้ทุกอย่างที่หน้านี้เท่านั้น หน้าแบบฟอร์มที่เปิดพิมพ์แก้ไม่ได้ ช่องที่ยังขาดบนแบบฟอร์มเป็นแถบเหลือง คลิกแล้วจะกลับมาที่ช่องนั้นในหน้านี้ และแบบฟอร์มจะอัปเดตเองเมื่อแก้เสร็จ

    เขียว = ครบแล้ว เหลือง = เดามาให้ ควรตรวจ แดง = ต้องเติมเอง

  3. (ถ้าต้องการ) ใช้ตัวช่วยร่างด้วย Claude

    ในช่องที่ยังว่าง จะมีปุ่มตัวช่วย คัดลอกข้อความคำสั่ง (prompt) ไปวางใน Claude แล้วนำคำตอบ (JSON) กลับมาวาง ระบบจะเติมให้ (ไม่มีการเรียก AI อัตโนมัติ คุณเป็นคนทำเอง)

  4. บันทึกงานไว้ทำต่อ

    กดปุ่ม บันทึกงาน (.json) เพื่อเก็บไฟล์งานไว้ในเครื่อง ครั้งหน้ากด เปิดงาน หรือลากไฟล์ .json มาวางในกรอบอัปโหลด เพื่อทำต่อได้ โดยไม่ต้องอัปโหลดข้อเสนอใหม่ (อย่าอัปโหลดไฟล์ข้อเสนอซ้ำทับงานที่แก้ไว้ เพราะระบบจะอ่านไฟล์ใหม่ และค่าที่แก้ด้วยมือจะหายไป)

  5. เปิดแต่ละแบบฟอร์มแล้วพิมพ์เป็น PDF

    เปิดแบบฟอร์มที่ต้องการ (AP 01_1, AP 01_2, AP 02, AP 03_1, แบบแจ้งค่าธรรมเนียม) กดปุ่ม พิมพ์ / บันทึก PDF แล้วเลือกปลายทางเป็น Save as PDF ขนาดกระดาษ A4

    แบบฟอร์มใช้ฟอนต์ TH Sarabun New ที่ติดตั้งในเครื่อง ถ้าตัวอักษรบนแบบฟอร์มไม่ใช่ฟอนต์สารบรรณ ให้ติดตั้งฟอนต์ก่อนพิมพ์ ดู วิธีติดตั้งฟอนต์

ติดตั้งฟอนต์ TH Sarabun New

แบบฟอร์ม EC ใช้ฟอนต์ TH Sarabun New ขนาด 16 พอยต์ เหมือนแบบฟอร์มต้นฉบับ หน้าเว็บไม่ได้ส่งฟอนต์นี้มาให้ จึงต้องมีในเครื่องของคุณ ทั้งตอนพิมพ์เป็น PDF และตอนเปิดไฟล์ Word (.doc) ที่บันทึกจากแบบฟอร์ม

รู้ได้อย่างไรว่ายังไม่มีฟอนต์

  • ตัวอักษรบนแบบฟอร์มดูเป็นฟอนต์อื่น (หัวกลม ตัวใหญ่ หรือห่างกว่าแบบฟอร์มต้นฉบับ) และจำนวนหน้าเพิ่มขึ้นผิดปกติ
  • Windows: เปิด Settings > Personalization > Fonts แล้วค้นคำว่า Sarabun ถ้าไม่พบ TH Sarabun New แปลว่ายังไม่ได้ติดตั้ง
  • macOS: เปิดแอป Font Book แล้วค้นคำว่า TH Sarabun New

ดาวน์โหลด

ฟอนต์ TH Sarabun New ของ SIPA (ใช้ได้ฟรี สัญญาอนุญาต GPL 2.0 + Font exception) ดาวน์โหลดได้ที่ f0nt.com/release/th-sarabun-new กดปุ่ม ดาวน์โหลดฟอนต์ จะได้ไฟล์ .zip ที่มี 4 ไฟล์: ตัวปกติ ตัวหนา ตัวเอียง และตัวหนาเอียง ควรติดตั้งครบทั้ง 4 ไฟล์

Windows 10 / 11

  1. คลิกขวาที่ไฟล์ .zip ที่ดาวน์โหลด เลือก Extract All (แตกไฟล์)
  2. เปิดโฟลเดอร์ที่แตกออกมา เลือกไฟล์ .ttf ทั้ง 4 ไฟล์ (กด Ctrl ค้างแล้วคลิก)
  3. คลิกขวา เลือก Install (ติดตั้งเฉพาะผู้ใช้นี้ ไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง) หรือ Install for all users ถ้ามีสิทธิ์ผู้ดูแลเครื่อง
  4. ปิดเบราว์เซอร์ทุกหน้าต่าง แล้วเปิดใหม่ จากนั้นเปิดแบบฟอร์มอีกครั้ง

macOS

  1. ดับเบิลคลิกไฟล์ .zip เพื่อแตกไฟล์
  2. ดับเบิลคลิกไฟล์ .ttf ทีละไฟล์ แล้วกด Install Font (ติดตั้งแบบอักษร) ใน Font Book หรือลากทั้ง 4 ไฟล์ไปวางในหน้าต่าง Font Book
  3. ออกจากเบราว์เซอร์ให้สนิท (Cmd + Q) แล้วเปิดใหม่ จากนั้นเปิดแบบฟอร์มอีกครั้ง
  4. ถ้าใช้ Microsoft Word บน Mac แล้วสระหรือวรรณยุกต์ลอยผิดที่ ให้ติดตั้งรุ่นจากลิงก์ด้านบน (รุ่น 1.35 ขึ้นไป แก้ปัญหานี้แล้ว) ทับรุ่นเดิม

ข้อควรรู้เรื่องฟอนต์

  • ฟอนต์ Sarabun ของ Google Fonts เป็นคนละตัวกับ TH Sarabun New ขนาดตัวอักษรต่างกัน ใช้แทนกันไม่ได้ แบบฟอร์มจะยาวกว่าต้นฉบับ
  • เครื่องที่ติดตั้ง Microsoft Office ของมหาวิทยาลัยมักมี TH Sarabun New อยู่แล้ว ตรวจตามวิธีด้านบนก่อนติดตั้ง
  • ถ้าส่งไฟล์ Word (.doc) ให้ผู้อื่น เครื่องของผู้รับต้องมีฟอนต์นี้ด้วย มิฉะนั้น Word จะแสดงเป็นฟอนต์อื่น ไฟล์ PDF ไม่มีปัญหานี้ เพราะฝังฟอนต์ไว้ในไฟล์แล้ว

ข้อควรรู้

  • เอกสารที่ได้เป็น ร่างให้ผู้วิจัยตรวจทาน ก่อนยื่น ไม่ใช่การรับรองจริยธรรม
  • เครื่องมือ ไม่ส่งและไม่บันทึกข้อมูล ของคุณไว้ที่ใด ทุกอย่างทำงานในเบราว์เซอร์
  • เพื่อผลพิมพ์ที่ดีที่สุด แนะนำเปิดด้วย Google Chrome หรือ Microsoft Edge และติดตั้งฟอนต์ TH Sarabun New ในเครื่อง (วิธีติดตั้ง)
